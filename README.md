# Age Calculator — CodeAlpha Internship

A web-based age calculator built with HTML, CSS and JavaScript.

## Features
- Enter your date of birth (day, month, year)
- Get your exact age in years, months and days
- Input validation with clear error messages
- Works fully offline, no internet needed

## Tech Stack
- HTML5
- CSS3
- JavaScript (Date object)

## How to use
1. Enter your day, month and year of birth
2. Click the **Calculate my age** button
3. Your age appears instantly
